# 1단계: 질문을 가설로

## 관심 분야

3D 게임(특히 지도 정보가 불친절한 게임)에서의 길찾기 경험과, 개인의 방향감각(이하 "길치") 사이의 관계.

## 검토한 후보 주제와 접은 이유

### 출발점

주변으로부터 "공동체(소외계층 등)를 다루는 주제가 스토리적으로 좋다"는 조언을 먼저 들음. 이를 받아들여 "어려움을 겪는 집단에는 어떤 집단들이 있을까"라는 질문에서 출발했으나, 소외계층처럼 소수의 집단을 대상으로 하기에는 본인이 아는 바가 적고 조심스럽게 다뤄야 하는 주제라고 판단함. 이에 역발상으로, 난독증·길치처럼 "흔히 볼 수 있지만 동일하게 어려움을 겪는" 집단으로 범위를 좁힘. 그중 본인이 실제로 속해 있는 "길치"를 최종 선택했는데, 본인이 겪는 어려움이기 때문에 핵심을 더 잘 짚어낼 수 있고 공감도 잘 이끌어낼 수 있다고 판단했기 때문임.

### 1차 후보군 (길치 × 게임)

- 3D/2D 게임에서 미니맵·풀맵 등 지도 요소의 유무가 길찾기 학습 속도에 미치는 영향
- 지도가 불친절한 게임을 반복 플레이하면 실제 오프라인 길찾기 능력이 개선되는지 (훈련 효과)
- 길치 정도가 지도가 불친절한 게임에서의 맵 습득 속도·탈출 실패 빈도에 미치는 영향
- 청각적 신호(발소리 등 방향성 사운드)와 길치의 관계
- 게임 내 공동체 요소(스쿼드 의존, 길치임을 밝히는지 여부)와 소속감의 관계

### 접은 후보와 이유

| 접은 주제 | 접은 이유 |
|---|---|
| 지도 유무(미니맵)가 길치에 미치는 영향 | 기존 내비게이션·UX 연구에서 이미 많이 다룬 주제라 차별성이 부족함 |
| 지도가 불친절한 게임을 장기간 플레이했을 때의 훈련(개선) 효과 | 사전-사후 비교가 필요해 최소 몇 주가 걸림 — 1주일 내 데이터 확보 기준을 넘어감 |
| 지도가 불친절한 실제 상용 게임의 플레이 로그 분석 | 게임마다 맵 구조가 다르고 UI를 임의로 바꿀 수 없어 변수 통제가 불가능함 |
| 게임 내 소속감·공동체 배제 관련 주제 (길치 사실을 밝히는지 여부 등) | 스토리성은 강하지만 스쿼드원 협조 등 데이터 수집 난이도가 높아 1주일 내 실행이 어려움 |

## 최종 가설 (2차 수정본)

> 3D 공간 탐색에서, 서로 다른 음색을 가진 고정 청각 랜드마크의 개수(0개/2개/3개)는 길찾기 소요 시간과 경로 효율성에 영향을 주며, 이 효과는 평소 공간지각능력이 낮은(길치인) 사람일수록 일반인보다 더 크게 나타난다.

> (1차 수정본: "목적지를 안내하는 청각적 신호(ON/OFF)" — 방향을 직접 알려주는 방식이라 "정답을 알려주는 것"에 가깝다는 지적을 받아, 방향을 직접 알려주지 않고 참가자가 스스로 위치를 종합 추론(삼각측량)해야 하는 고정 청각 랜드마크 방식으로 변경함. 자세한 논의 과정은 대화 기록 참고.)

## 무엇이 무엇에 영향을 주는가

- 독립변수: 청각 랜드마크 개수 (0개 / 2개 / 3개, 서로 다른 음색 — 완전히 같은 소리는 애매함이 안 풀린다는 선행연구에 따라 반드시 서로 다른 음색으로 구성)
- 조절변수: 개인의 길치 정도(공간지각능력, R-SOD 연속 점수)
- 종속변수: 목적지 도달까지 걸리는 소요 시간, 경로 효율성(최단경로 거리 대비 실제 이동 거리 비율)
- 부가 종속변수: 갈림길에서 멈춰 서서 방향을 탐색(재정향)한 시간, 막다른 길 진입 횟수

## 측정 방법

- 길치 정도: SBSOD(Santa Barbara Sense of Direction Scale)의 검증된 4문항 단축판인 R-SOD(Jaswal, Burles, & Iaria, 2025)로 측정. 원 논문은 11.5점을 임상적 컷오프로 제시하지만, 이는 희귀 질환(DTD) 진단용 기준이라 4~6명 규모의 비임상 표본에는 부적합할 수 있음 — 그룹으로 나누지 않고 **연속 점수 그대로 상관관계 분석**에 사용한다.
- 소요 시간: 자체 제작한 3D 시뮬레이션 내에서 출발선 통과~목적지 도달까지 자동 타이머로 초 단위 기록
- 경로 효율성: 그리드 최단경로 길이(BFS로 계산) 대비 실제 이동 거리의 비율
- 부가 측정: 갈림길 재정향 시간, 막다른 길 진입 횟수

## 가설이 틀렸을 경우 예상되는 결과

- 랜드마크 개수와 무관하게 소요시간·경로 효율성에 차이가 없다면 → 청각 랜드마크가 실질적인 지도 형성에 도움이 되지 않는다는 결론
- 2개와 3개 사이에 차이가 없다면 → 애매함 해소에 반드시 3개(삼각측량)가 필요하다는 선행연구(Jetzschke et al., 2017)의 결과가 이 과제/환경에서는 재현되지 않는다는 결론
- 길치 정도와 무관하게 효과 크기가 비슷하다면 → 청각 랜드마크는 개인의 공간지각능력과 무관하게 균일하게 작용한다는 결론
- 이 결과들 모두 원래 가설과 다르지만 그 자체로 의미 있는 발견임

## 데이터 수집 기간과 범위

- 참가자: 지인 4~6명
- 기간: 약 1주일
- 시행 구성(1인당): 워밍업 1회(분석 제외) + 본시행 3회(랜드마크 0개/2개/3개 각 1회), 맵 3종(난이도 동일, 회전·반전으로 생성)에 조건·순서를 참가자별로 역균형화하여 배정

## AI와 가설을 다듬은 과정 (요약)

1. "공동체를 다루는 주제가 좋다"는 외부 조언에서 출발해 "어려움을 겪는 집단"을 후보로 탐색
2. 소외계층 등 소수 집단은 아는 바가 적고 조심스러운 주제라 판단해, 흔히 볼 수 있지만 동일하게 어려움을 겪는 집단(난독증, 길치 등)으로 방향을 바꾸고, 그중 본인이 속한 "길치"를 선정(핵심 파악과 공감이 쉬움)
3. 길치와 3D 게임(지도가 불친절한 게임 포함)을 엮은 후보를 다수 브레인스토밍
4. 청각적 신호로 후보를 좁히는 과정에서, "청각 신호가 길치에 영향을 준다"는 초기 문장이 측정·기간 기준을 통과하지 못함을 확인하고 상관관계 중심으로 재구성
5. 상용 게임 대신 직접 3D 시뮬레이션을 만들어 조건을 통제하는 방식으로 구체화
6. 단순 효과 가설(안1)과 상호작용 효과 가설(안2)을 놓고 비교, 실험에 길치 자가진단 설문을 포함시키기로 하면서 안2로 최종 확정
7. 외부 조언을 추가로 검토해 실험 설계 보완점(역균형화, 헤드폰 필수, 기기 통일, 워밍업, 타임아웃)을 반영
8. 시뮬레이션 1차 구현("목적지 비콘형" 청각 신호) 후, "이 설계는 청각 신호가 사실상 정답을 알려주는 것이라 결과가 무조건 한 방향으로 나올 수밖에 없다"는 지적을 받고 재검토
9. 정답을 직접 알려주지 않으면서 참가자가 스스로 공간을 종합 추론하게 만드는 "고정 청각 랜드마크(삼각측량)" 방식으로 청각 신호를 재정의하고, 랜드마크 개수(0/2/3)를 독립변수로 하는 설계로 전환
10. 재검색한 선행연구(Jetzschke et al., 2017)가 "서로 다른 소리 3개일 때만 애매함이 풀린다"는 것을 이미 검증했음을 확인, 이 메커니즘을 가설과 측정 지표(경로 효율성, 재정향 시간)에 반영

## 최종 가설을 고른 이유

- 단순히 "소리가 도움이 되는가"보다 "길치인 사람에게 더 크게 도움이 되는가"를 보는 것이 본인의 실제 경험(길치)과 직결되어 서사가 뚜렷함
- 상용 게임이 아닌 직접 제작한 시뮬레이션을 사용해 변수를 완전히 통제할 수 있어 1주일 내 검증이 가능함
- 길치 자가진단 설문을 설계에 포함시킴으로써 추가 비용 없이 단순 효과와 상호작용 효과를 동시에 검증할 수 있음
- (수정 후) 랜드마크 방식은 정답을 직접 알려주지 않아 "무조건 한쪽이 이기는" 뻔한 결과를 피할 수 있고, 랜드마크 개수(0/2/3)라는 단계적 조작을 통해 선행연구(Jetzschke et al., 2017)가 밝히지 못한 "2개일 때의 중간 효과"까지 새롭게 확인할 수 있음
